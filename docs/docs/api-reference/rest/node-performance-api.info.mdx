REST contract of the node-performance bounded context of the retail network, derived from retail-network-docs model/model.yaml (contexts[node-performance].rest, .aggregates, conventions.errors) and adjusted by the cross-context decisions (G20, G33, E18). Node Performance grades every node from observed facts only (purchase orders issued, accepted, rejected and expired, packages handed over against requiredShipBy, promises kept or broken, inventory feeds applied) over a 7-day and a 30-day window. A scorecard below the observation minimum (50) is PROVISIONAL. Both routes are read-only, so none takes an Idempotency-Key. vendor-connectivity calls GET /scorecards/\{nodeId\} in-organization to serve a vendor's scorecard read; delivery-promise and order-sourcing do not call this API, they consume NodeScorecardUpdated. No authentication, consistent with the rest of the retail network. Errors are RFC 9457 problem details (application/problem+json); the problem types are not-found (404) and validation-failed (422).
